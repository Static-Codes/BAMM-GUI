This repository contains the source code for the [BrowserAutomationMaster](https://github.com/Static-Codes/BrowserAutomationMaster) Manager (BAMM) GUI. 

Originally, this code was stored under the `gui` branch on the repository above. Due to this parent repository HEAD reaching 2GB in size, this branch was orphaned into its own repository.

The orphaning process removed over 500 unrelated commits; these commits stemmed from `gui` being a branch off `main` (renamed to `stable`).

Starting with `v1.0.0A8`, all releases will pull the GUI files from this repository. as opposed to using the branch stored in the HEAD of the previous repository.
